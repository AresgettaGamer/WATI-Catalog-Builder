Analiza add-ons de Minecraft Bedrock y genera contribuciones normalizadas para WATI Core.

v1.2.1 · ESQUEMA 3 + CONOCIMIENTO 1
Privacidad: los paquetes se leen y procesan localmente. Esta página no los sube a ningún servidor.

1. Cargar paquete

Arrastra aquí .mcaddon, .mcpack o .zip Puedes cargar juntos el BP y el RP para obtener resultados más completos.

2. Identificación del proyecto

El Builder propone estos datos a partir del manifest, las traducciones y archivos de licencia. Revísalos antes de exportar.

Idiomas de nombres

Elige qué nombres se guardarán en la contribución. Los valores faltantes se generan desde el identifier y se marcan como tales.
